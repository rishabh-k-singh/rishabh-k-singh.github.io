How can one herder bring every agent to the target?

Each agent only moves away from the herder, with speed k/d2 at distance d.

Drag the herder and try it.

Proposed strategies

Strategy 1

A blind herder

It circles at a fixed speed and senses nothing, yet the agents gather on one small orbit around the target.

Agents start inside the region of attraction.

[C1]

Strategy 2

Sense one agent

The herder sets its radius from one agent's distance to the target, so it spirals in as the herd gathers.

[J1]

Closer to real robots

Give agents room

Both strategies send agents to one point, where real robots would collide. So agents also repel each other.

Proved: no collision in finite time. Estimated: herd size grows as γ1/3.
